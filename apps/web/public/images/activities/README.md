# Aset kegiatan relawan

Empat ikon dipisahkan dari mockup kegiatan relawan yang disetujui pada 4 Oktober 2026 melalui hasil konversi 12ui. Digunakan pada ringkasan status, bukan sebagai bukti laporan.

| File | Pemakaian |
| --- | --- |
| registration.png | Pendaftaran dibuka |
| in-progress.png | Kegiatan berlangsung |
| awaiting-result.png | Menunggu hasil |
| completed.png | Kegiatan selesai |

Foto sumber, bukti hasil, dan bukti timbangan di aplikasi berasal dari API yang memeriksa relasi dan izin akses. Foto contoh dalam mockup tidak dipasang sebagai pengganti foto backend.

Komponen memakai ikon Lucide untuk tindakan, navigasi, dan fallback saat foto tidak tersedia. Layout dan teks dibuat sebagai komponen React/CSS, bukan gambar satu halaman.

Sumber desain: paket `output/mockups/kegiatan-relawan-2026-10-04/contract-aligned-v2` di workspace, di luar repository. Kit konversi dan pratinjau sintetis disimpan di luar repository.
