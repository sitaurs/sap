# Aset Dampak SAP

12 aset PNG dipisahkan dari mockup yang disetujui pada 4 Oktober 2026. Batas aset mengikuti LayerDoc hasil 12ui. Ikon/kartu dan ilustrasi menggunakan crop lossless dari gambar asli untuk menjaga warna lingkaran dan ketajamannya; simbol navigasi mempunyai cutout transparan. Mapping semantik berada di `components/impact/impact-assets.ts`.

- 29: simbol Dampak; 58/62/66/70: ikon metrik.
- 76/115: verifikasi dan dasar perhitungan.
- 80/85/90: terkumpul, diserahkan, didaur ulang.
- 110: waktu respons; 114: ilustrasi tunas.

Ring 75% pada gambar sumber tidak dipakai sebagai bitmap: ring dirender sebagai SVG dari nilai `measurementCoverage` supaya persentasenya mengikuti data. Label, angka, filter, dan tombol merupakan elemen HTML interaktif. Logo menggunakan aset merek SAP yang sudah ada.
