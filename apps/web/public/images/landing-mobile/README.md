# Aset landing page mobile SAP

Aset dipisahkan dari mockup mobile SAP yang disetujui pada 5 Oktober 2026. Gambar foto memakai crop dari mockup; ilustrasi dan daun memakai raster/cutout hasil konversi 12ui. Semua dioptimalkan menjadi WebP. Logo SAP, ikon Lucide, dan avatar contoh pelanggan menggunakan aset existing.

| File | Ukuran | Pemakaian |
| --- | --- | --- |
| `hero-camera.webp` | 441 × 396 | Foto hero: ponsel memindai botol plastik |
| `bottle-scan.webp` | 338 × 164 | Contoh hasil scan pada alur laporan |
| `report-photo.webp` | 136 × 158 | Contoh foto laporan pada alur verifikasi |
| `review-illustration.webp` | 664 × 362 | Ilustrasi pemeriksaan admin, transparan |
| `verified-area.webp` | 322 × 167 | Ilustrasi area terverifikasi |
| `leaf-soft.webp` | 88 × 120 | Dekorasi hero, transparan |
| `menu-foliage.webp` | 326 × 562 | Dekorasi panel menu, transparan |
| `footer-leaves.webp` | 144 × 134 | Dekorasi footer, transparan |

Ukuran, byte, dan informasi alpha tercatat dalam `manifest.json`. Delapan gambar berjumlah 115.596 byte sebelum optimasi responsif Next Image.

Gambar ini ilustrasi untuk landing page, bukan bukti laporan pengguna, data hasil model, atau gambar peta API. Peta publik tetap memakai komponen peta interaktif existing. Gambar UI lengkap tidak dijadikan screenshot yang menggantikan komponen interaktif; teks, tombol, menu, form contoh, dan footer dirender sebagai HTML.
