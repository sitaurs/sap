# Aset detail kegiatan

Aset disiapkan sebelum implementasi pada 8 Oktober 2026.

- lake-background.webp: latar alam bersih, dibuat dengan built-in imagegen dari gambar pertama pengguna. Semua antarmuka dan teks dihapus, pemandangan yang tertutup direkonstruksi sambil mempertahankan danau, gunung, palet biru lembut, dan daun di tepi.
- leaf-card.webp: potongan asli dekorasi daun kartu keikutsertaan.
- nature-quote.webp: potongan asli kutipan tulisan tangan.

Batas potongan dan asal file dicatat di manifest.json. Logo memakai aset SAP asli; ikon memakai Lucide. Tidak ada teks informasi kegiatan atau data pengguna yang dijadikan gambar.

Prompt latar: Extract only the scenic background. Remove every UI element and all text. Preserve the pale blue daylight, calm lake, forested misty mountains, shoreline and blurred foreground foliage. Reconstruct areas covered by interface. Output a clean 16:9 background without text, logo, buttons, cards, borders, people or extra buildings.
