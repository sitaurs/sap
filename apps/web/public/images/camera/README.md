# Aset kamera SAP

- `focus-frame.svg`: empat sudut mint dari desain yang disetujui; vektor responsif.
- `camera-idle.svg`: ikon kamera untuk keadaan menunggu/izin gagal, tanpa foto contoh.
- Ikon tombol menggunakan `lucide-react`, sama seperti dashboard: Camera, Image, SwitchCamera, Flashlight, X, ArrowLeft, ShieldCheck.
- Warna, tombol shutter, backdrop, dan panel dipisahkan ke `components/camera-capture.module.css`.
- Foto pada mockup hanya referensi. Preview memakai MediaStream perangkat; foto hasil tangkapan dibuat lokal sebagai JPEG, lalu memakai unggahan scan yang sudah ada saat pengguna memilih Pindai dengan AI.

Tidak ada gambar botol contoh yang digunakan sebagai preview kamera hidup.
